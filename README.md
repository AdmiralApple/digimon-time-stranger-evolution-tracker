# Time Stranger Tree

An unofficial, spoiler-aware evolution atlas and route planner for
*Digimon Story: Time Stranger*.

**[Open the live app](https://admiralapple.github.io/digimon-time-stranger-evolution-tracker/)**

The app maps 475 forms, supports save-file-based discovery, highlights direct
evolution relationships, and plans multi-step evolution and de-evolution routes.
Save files are parsed locally in the browser and are never uploaded.

## Development

```sh
cd app
npm install
npm run dev
```

Run `npm test` for the test suite and `npm run build` for a production build.
More implementation details are available in [`app/README.md`](app/README.md).
